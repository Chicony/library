🔐 Вход в библиотеку

Для синхронизации между устройствами нужен GitHub токен:

  1. Создайте аккаунт на GitHub (бесплатно)
  2. Перейдите в Settings → Developer settings → Personal access tokens
  3. Нажмите "Generate new token (classic)"
  4. Дайте имя (например "Library"), выберите scope gist
  5. Скопируйте токен и вставьте ниже
